# Roadmap

## Shortterm Goals

- add tgtg and tgtg-cli as commands to start application
- add default commands to CLI (like --help, --version)
- add and configure ty as type checker
- test checkout with non 3DS card
- add option to register new account
- better handling for keyboard interrupts at all times

## Longterm Goals

- write automated tests
- improve logging to make debugging easier (e.g. during automatic retries)
- improve styling of console (e.g. with Textual)
- option to monitor more than one item at once
- option to adjust quantity to check out for an item
- clearer separation of API, Service and CLI layers
- simplify error handling in TGTG client to make it more intuitive
